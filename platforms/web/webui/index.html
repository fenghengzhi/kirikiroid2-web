关于本站

在浏览器里直接运行 Kirikiri2（吉里吉里2）引擎的视觉小说，不需要安装任何东西。引擎经 WebAssembly 编译，游戏完全在你的设备上运行——存档和游戏文件都不会上传。

用法

  • 从游戏库点开任意一作，直接开始
  • 也可以「打开本地文件」，读取自己的 .xp3 档案、.zip 整包或游戏文件夹
  • 存档按游戏自动分开保存，可导出 .zip 备份或换设备时导入

游戏中

  • 画面上没有任何常驻元素。电脑上把鼠标移到屏幕最顶端唤出控制栏
  • 手机上从顶边下滑唤出控制栏；开局那几秒顶部中间会有个小箭头，淡出后原位置仍然可以点
  • 控制栏里可以退出游戏、管理存档、切换全屏；F 键也能切全屏

浏览器要求

需要支持 WebAssembly 与 WebGL 的现代浏览器。推荐用最新版 Chrome / Edge；Safari 需要 27（iOS 27）及以上。手机和平板都能跑。
