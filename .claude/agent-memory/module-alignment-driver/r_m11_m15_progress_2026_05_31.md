1. **CLAUDE.md 1:1 政策应用即可决策**: M11 5 alias 绑定违反"binary apparent bug"的语义, 我之前升级为"用户决策卡点". 用户指出过度防御 — 实际 CLAUDE.md 已经说了 1:1 wins. 直接执行后 CI green 印证. 后续此类政策应用不再升级.

2. **空字段类型修正与 wire 行为脱钩**: R-M4 修 HM4 value 类型完全无运行时影响 — 字段 empty, 验证只是确认 audit memory 错位 (将 R-M4 看作 "纯文档修正" 而非真的 1:1 推进). CLAUDE.md "复刻源代码结构" 指有数据流通过的结构, 不是空字段类型注解.

3. **NCB 端口扩展面巨大**: 港口 Motion.Player NCB 138 项, binary 92 项. 70 项 local-only 是端口为方便 web TJS 加的, 但违反 binary 类边界. 移除 →logo 用 D3DEmotePlayer wrapper 路径仍能跑.

4. **CI 容忍度高于预期**: 移除 30 个 NCB binding 一次 commit 仍预期 green (依据是 logo TJS 不直接调 Motion.Player.playTimeline 而走 D3DEmotePlayer wrapper). 大 batch 比小 batch 更高效.
