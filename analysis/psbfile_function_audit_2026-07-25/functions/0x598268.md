## Android 伪代码（10 行）

```text
Load(value):
    if value.type == String: path=fresh_ttstr(value.string); ok=LoadStorage(path,{})
    if value.type == String: if !ok throw "cannot open psb file : %1"; return true
    if value.type != Octet: throw "invalid argument for PSBFile.load()"; return true
    size=value.octet.length; source=value.octet.data; data=null
    if size>=11 && u32(source)==0x0066646D: data=AlignedAlloc(u32(source+4),4); actual=expected
    if MDF && uncompress(data,&actual,source+8,size-8)==OK: size=actual
    else if MDF: delete[] data; data=null
    if data==null: data=AlignedAlloc(size,4); memcpy(data,source,size)
    if Adopt(data,size,{}): return true; delete[] data; throw "octet: invalid psb file."; return false
```

`MDF` 在第 7-8 行只代表第 6 行的长度/签名 gate 已成立；签名不匹配或不足 11 字节直接
落入第 9 行。伪代码覆盖默认空 filter、三类输入、解压成功/失败/空目标、两个 helper 的
false、三个精确异常文本、异常 helper 反常返回值以及 allocation 的交接/回收边界。
