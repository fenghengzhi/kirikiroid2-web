## Android 伪代码（10 行）

```text
OwnerCtor(self,data,u64 size):
    self.refCount=0
    self.data=data; self.size=size
    if data==null: return self                 // header/headerStorage 保持未初始化
    self.header=&self.headerStorage
    self.headerStorage.{signature,version,encrypt}={u32(data),u16(data+4),u16(data+6)}
    self.headerStorage.{encryptData,names,strings,stringsData}=data+u32(data+{8,12,16,20})
    self.headerStorage.{chunkOffsets,chunkLengths,chunkData,entries}=data+u32(data+{24,28,32,36})
    return self                                // 不分配、不 AddRef、不验证 size/signature/offset
// self 非法或非空 data 不可读时 raw access 失败；无 catch、回滚或 fallback
```

第 7、8 行中的花括号表示四个彼此独立、按列对应的读取与 store，不表示 vector、循环或一次
聚合复制；Android 实际是八组展开的 `LDR W`、`ADD`、`STR X`。
