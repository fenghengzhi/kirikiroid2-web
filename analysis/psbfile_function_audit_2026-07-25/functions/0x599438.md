## Android 伪代码（9 行）

```text
GetInt(self) -> signed32:
    node = self.node; tag = node[0]                 // self/node 无 null 防护
    tag 02 -> 1; tag 03 or 04 -> 0
    tag 05/06/07/08 -> sign_extend(le8/le16/le24/le32(node+1))
    tag 09 -> low32(sign_extend40(node+1)); tag 0A -> low32(sign_extend48(node+1))
    tag 0B -> le32(node+1) only; tag 0C -> low32(le64(node+1))
    tag 1D -> 0; tag 1E -> trunc_s32(le_f32(node+1)); tag 1F -> trunc_s32(le_f64(node+1))
    default -> sub_95440C(L"psb: can't convert value to int."); if it returns, result = 0
    return result
```

以上覆盖全部 tag 分支、默认值、符号/宽度转换、无 null 防护、各编码宽度的读取边界以及
异常 helper 返回时的显式零值。
