## Android 关键伪代码（7 行）

```text
GetString(self): node=self.node; tag=node[0]
if GetTypeCategory(tag)!=4: return null // unknown 抛错；helper 反常返回也为 null
h=self.owner.header
offsets=PsbArray(h.strings)
index = tag==15?u8(node+1) : tag==16?u16(node+1) : tag==17?u24(node+1)
      : tag==18?u32(node+1) : 0       // category-4 的 2C 默认 index 0
return h.stringsData+offsets[index]    // width 1..5；无效 width→0；无其他 gate
```

`PsbArray` 这一源码层次与共享 classifier 分层由同谱系 iOS arm64 retained calls 支持。
其 element 行为由 Android
的 unaligned 32-bit load、W32 index product 与
`0xFFFFFFFF >> (8*(0x10-widthTag))` variable-shift mask 独立约束。
