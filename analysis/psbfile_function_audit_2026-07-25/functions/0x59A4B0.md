## Android 关键伪代码（10 行）

```text
Resolve(name,out): dispatch=_file.AsObjectNoAddRef(); file=GetNativeInstance(dispatch)
  owner=file->owner; current={owner,owner->header->entries}; retain(current.owner)
  first=name.IndexOf('/',0); if first==-1: destroy current; return false (out unchanged)
  rest=name.SubString(first+1,-1); loop: slash=rest.IndexOf('/',0); last=(slash==-1)
  segment=""; if last segment=rest; else segment=rest.SubString(0,slash)
  if !last: rest=rest.SubString(slash+1,-1)
  key=Narrow(segment); if !current.ContainsDictionaryKey(key): cleanup; return false
  current=current.GetDictionaryValueStrict(key); on throw, unwind key/segment/rest/current
  destroy key/segment; if !last continue; out=current (release-old, copy, retain, copy-node)
  destroy rest/current; return true; invalid _file/adaptor/file/owner/header has no fallback
```
