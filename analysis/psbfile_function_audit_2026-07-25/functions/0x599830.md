## Android vtable / NCB / 调用链归属

`0x599830` 是 Android `PSBMedia` vtable `0x1A0B510` 的第二个 qword
（slot 1），与 slot 0 的 complete-destructor 入口组成 Itanium C++ ABI 的
析构对。本节点本身不是 NCB wrapper；canonical parent `0x59849C` 在构造
进程期 `PSBMedia` 时安装该 vtable，因此 TASK_TREE 使用 `[vtable-member]`，
不能表述成 `0x59849C -> 0x599830` 的直接调用。

运行期通过多态删除语义进入本槽。正常路径直接展开完整成员清理，再尾调用全局
`operator delete`；反汇编中没有对 `0x5997F0` 的 `BL`。所以 TASK_TREE 将
`0x5997F0` 置为本节点的 `[lifecycle]` child 只是析构变体的 canonical 归属，
不是保留下来的直接调用边。
