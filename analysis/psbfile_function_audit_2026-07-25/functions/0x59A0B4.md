## Android vtable / NCB / 调用链归属

`0x59A0B4` 是 `PSBMedia` 的 private raw-resource helper，本身既不在
`PSBMedia` vtable，也不是 NCB typed wrapper。运行时从 storage-media 两个虚方法
直接进入：vslot 7 `CheckExistentStorage@0x5998C4` 和 vslot 8
`Open@0x59993C`。canonical spanning tree 选择前者作为唯一 parent；后者仅是
cross-reference。

本节点的 Android emitted 调用/辅助关系为：

```text
PSBMedia vslot 7 @0x5998C4 ─[direct]→ @0x59A0B4
PSBMedia vslot 8 @0x59993C ─[direct, cross-reference]→ @0x59A0B4
@0x59A0B4 ─[direct]→ @0x59A4B0 Resolve_guess
@0x59A0B4 ─[complete inline clone; no BL]→ @0x5996E4 PSBRawNode_GetResource_guess
```

`0x59A4B0` 的 canonical parent 按 TASK_TREE 保留为 `0x5999F4`，不得从本节点
重复派发；`0x5996E4` 则是本节点唯一 canonical child，边严格为 `[helper]`。

## Android 关键伪代码（9 行）

```text
GetResourceData(self, name, size_out): out = {owner:null, node:null}
try: if !Resolve(self, name, out): destroy(out); return null        // size 不写
h = out.owner.header; if h.chunkData == null: destroy(out); return null // size 不写
index = tag(out.node) 为 19/1A/1B/1C ? 读 u8/u16/u24/u32 : 0
*size_out = packedWidth(h.chunkLengths) 在 0D..11 ? packed[length,index] : 0
offset = packedWidth(h.chunkOffsets) 在 0D..11 ? packed[offset,index] : 0
result = h.chunkData + offset                                      // 无表长/index 检查
destroy(out): 若 owner && --ref==0，则释放 raw allocation 并 delete owner；return result
catch: destroy(out); rethrow；stack canary 失配则 __stack_chk_fail
```

成功返回值是借用的 chunk 指针；本函数不为它额外 retain owner。`size_out` 没有
null guard，只有 Resolve 成功且 `chunkData` 非空后才解引用并写入。
