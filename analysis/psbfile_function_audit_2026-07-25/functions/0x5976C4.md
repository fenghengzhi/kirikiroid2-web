## Android 伪代码（10 行）

```text
PropGetByNum(self, flag, num, result, objthis):
    if !self.valid || self.value.owner == null: return -1006
    category=GetTypeCategory(*self.value.node)
    if category != 6: return -1001              // unknown helper-return 也走此 continuation
    packed=node+1; count=decode(0D:u8,0E:u16,0F:u24,10:u32,default:0)
    index=W32(num + (num<0 ? count : 0)); compare index/count as signed int32
    if index<0 || index>=count: if flag&0x400 return -1001; else Clear(result); return 0
    re-decode count; widthTag=packed[countTag-0x0B]; width=widthTag-0x0C; entry=(width in 1..5)?maskedLE32(packed+countTag-0x0A+index*width):0
    CreateVariant(self,result,packed+SXTW(W32(count*width+countTag-10+entry))); return 0
```

其中 `Clear(result)` 与命中后的 `CreateVariant` 都没有 result null guard；node 与 packed 输入也没有
边界校验。伪代码覆盖 valid/owner gate、完整 tag 分类、count 默认值、负索引、strict/non-strict
越界、非法宽度、未知类型异常以及成功返回边界；`objthis` 和除 `0x400` 外的 flag 位不参与。
