## Android 伪代码（7 行）

```text
FactoryDeletingDestructor(self):
    tTJSDispatch::~tTJSDispatch(self)       // trivial derived/base destructors collapse here
        old = self.BeforeDestructionCalled
        self.vptr = tTJSDispatch_vtable
        if old == false: self.BeforeDestructionCalled = true  // empty base hook is optimized out
    ::operator delete(self)
    return                                  // no status/default/failure return path
```

目标入口没有额外条件或默认值；唯一条件位于其直接调用的基类析构中，用于保证
`BeforeDestruction` 生命周期钩子至多执行一次。对 null/失效 `self` 没有保护，这类调用
违反 C++ 析构 ABI；正常入口也不允许在此恢复失败或返回错误码。
