## Android 伪代码（9 行）

```text
vector<string>::reserve(v, n):
    if n >= 2^61: throw length_error("vector::reserve")
    oldBegin=v.begin; if n <= (v.capacityEnd-oldBegin)/8: return v unchanged
    oldEnd=v.end; oldBytes=oldEnd-oldBegin; newBegin=operator new(8*n)  // bad_alloc: v unchanged
    for src in [oldBegin,oldEnd): transfer src.COWData to next new slot; src.COWData=emptyRepData
    for src in [oldBegin,oldEnd): destroy moved-from string; skip empty rep, else --ref and delete at prior<=0
    if oldBegin != null: operator delete(oldBegin)
    v={begin:newBegin, end:newBegin+oldBytes, capacityEnd:newBegin+8*n}; return
    if stack canary changed: __stack_chk_fail()
```

该伪代码覆盖超长请求、no-op/default unchanged、空 vector、分配异常、完整迁移与析构、旧
buffer 的 null gate、最终三指针值和栈保护失败边界。合法 C++ vector 前提之外的悬空/错序
三指针属于标准容器 UB；Android 本体没有额外防护。
