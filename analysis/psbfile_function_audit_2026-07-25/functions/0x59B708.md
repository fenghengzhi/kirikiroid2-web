## Android 伪代码（9 行）

```text
Variant ExtractFirstArgument(functor):
    Variant ret                         // default = tvtVoid
    if functor.numparams >= 1: Variant arg(*functor.param[0])  // no null gate
    else: Variant arg                   // default = tvtVoid
    ret = arg; destroy(arg)             // CopyRef, AddRef-before-release
    Variant return_tmp(ret); construct sret from return_tmp
    destroy(return_tmp); destroy(ret); return sret
    on copy/assignment exception: destroy only constructed temporaries in reverse order; rethrow
    on stack-canary mismatch: __stack_chk_fail
```

本入口不调用 `PSBFile::Load`、不写 TJS result，也不产生 TJS error code；正常 NCB
调用中 parent 已先检查 `argc >= 1`，但本 emitted helper 自身仍保留缺参时的
`tvtVoid` 默认分支。
