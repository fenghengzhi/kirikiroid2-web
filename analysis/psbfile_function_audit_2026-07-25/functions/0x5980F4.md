## Android 伪代码（9 行）

```text
Factory(result, count, params, objThis):
    file = new PSBFile(owner=null)                 // 分配失败：传播，result 尚未写
    *result = file
    try:
        if count >= 1:
            tmp = copy(*params[0]); ignore file.Load(tmp)
            destroy(tmp)
    catch (...): destroy constructed tmp if needed; delete file; rethrow  // 不清 *result
    return TJS_S_OK
```

伪代码覆盖空参数/负数参数数、多参数只取首项、默认空 owner、按值临时量、被忽略的 Load
返回值、分配失败、copy/Load 异常清理和悬挂结果槽边界。`count >= 1` 时 Android 直接解引用
`params` 与 `params[0]`，没有为违反 NCB ABI 的 null 参数表增加保护。
