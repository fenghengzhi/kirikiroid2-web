## 总判定

`EVIDENCE_LIMITED`

所有 Android 当前可见的结构 shape、数据流、真实 caller、生命周期与边界均和本地一致，
没有确定行为或架构 GAP。target 与 iOS arm64 共同支持 X1 是
PSBFile-compatible 一指针 holder，不再允许把裸 owner-slot 作为同等自由候选；总判定仅
受限于共同 holder 的原始类型名、raw node 的 member/base/accessor token及精确构造函数
符号。这属于证据上限，不是已证明偏差。

caller 不消费 `X0` 与三条 new-expression EH cleanup 共同证明它是普通 constructor 的隐式
