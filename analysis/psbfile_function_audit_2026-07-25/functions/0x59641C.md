## Android 关键伪代码（10 行）

~~~text
// 无 null/长度保护；以下任一 false 都不写 outIndex
read(base,widthTag,i) = (widthTag-0x0D >u 4) ? 0 : load32(base+u32(i*(widthTag-0x0C))) & shiftMaskModulo32(widthTag)
tag=names[0]; count = tag==0x0D?u8(names+1):tag==0x0E?u16(names+1):tag==0x0F?u24(names+1):tag==0x10?u32(names+1):0
baseWidth=names[tag-0x0B]; base=names+tag-0x0A; checkHdr=names+u32(tag-0x0A+count*(baseWidth-0x0C))
checkTag=checkHdr[0]; checkWidth=checkHdr[checkTag-0x0B]; check=checkHdr+checkTag-0x0A
byte=u8(name[0]); parent=0; state=u32(read(base,baseWidth,0)+byte)
if state >=u count: return false
loop: if read(check,checkWidth,state) != parent: return false
if byte==0: *outIndex=read(base,baseWidth,state); return true
byte=u8(*++name); parent=state; state=u32(read(base,baseWidth,state)+byte); if state>=u count: return false; goto loop
~~~

`shiftMaskModulo32` 是 `0xFFFFFFFF >> (8 * (0x10-widthTag))` 的 AArch64
register-shift 语义；因此 width tag `0x11` 的 shift 按 32 取模后为 24。
