## Android 关键伪代码（9 行）

```text
GetDictionaryValueStrict(self,key,result):
  if !FindNameIndex(self.owner.header.names,key,&nameIndex) ||
     !FindDictionaryValueOffset(self.node+1,nameIndex,&valueOffset):
    tmp=ttstr_from_narrow(key); Throw(L"psb: undefined object key '%1' is referenced.",tmp)
    release(tmp); result.owner=null; result.node=null; return  // 仅当 Throw 返回
  result.owner=self.owner
  if result.owner != null: ++result.owner.refCount
  result.node=self.node+1+valueOffset; return
  // 无 self/owner/header/node/key、node-type 或 packed-range fallback；异常继续 unwind
```
