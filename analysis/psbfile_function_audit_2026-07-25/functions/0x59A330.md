## Android 关键伪代码（10 行）

```text
CreateAdaptor(file, sticky, throwOnFail):  // canonical caller @599F18 passes false,false
  cls = ClassInfo.classObject; if !cls: if throwOnFail throw "No class object."; return null
  global = GetScriptDispatch(); dummy = Void; obj = null
  r = cls.CreateNew(0,null,null,&obj,1,&dummy,global); if global: global.Release()
  if FAILED(r) || !obj: if throwOnFail throw "Can't create instance"; else destroy(dummy), return null
  adaptor = null; r = obj.NativeInstanceSupport(GETINSTANCE, ClassInfo.id, &adaptor)
  if FAILED(r): if throwOnFail throw "Invalid instance type."; else return obj
  if adaptor: adaptor.instance = file; if sticky: adaptor.sticky = true
  destroy(dummy); return obj  // adaptor==null 也返回 obj；helper 从不 delete file
  exception: destroy constructed dummy and rethrow; CreateNew 抛出前取得的 global 不会补 Release
```
