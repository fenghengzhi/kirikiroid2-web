## Android 关键伪代码（9 行）

```text
GetDictionaryValue(self,key,out):
  if !FindNameIndex(self.owner.header.names,key,&nameIndex): return false  // out 不变
  if !FindDictionaryValueOffset(self.node+1,nameIndex,&valueOffset): return false  // out 不变
  savedNode=self.node; oldOwner=out.owner
  if oldOwner!=null: --refCount; if zero: destroy payload (throw => terminate); delete owner
  out.owner=self.owner
  if out.owner!=null: ++out.owner.refCount
  out.node=savedNode+1+valueOffset; return true
  // packed helper 异常传播；无 type/null/range/alias guard
```
