## Android 伪代码（9 行）

```text
emplace_back_aux(vector, value_lvalue):
    n=(finish-start)/sizeof(string); grow=(n != 0 ? n : 1)
    cap=overflow_or_over_max(n+grow) ? max_size : n+grow
    newbuf = cap ? allocate(cap*sizeof(string)) : null  // bad_alloc propagates
    try copy_construct(newbuf+n, value_lvalue)
    catch: delete(newbuf); rethrow                       // old vector unchanged
    for each old element: transfer its COW pointer to newbuf; reset old to empty singleton
    destroy old elements; delete old buffer
    start=newbuf; finish=newbuf+n+1; end_of_storage=newbuf+cap
```

伪代码覆盖空 vector 默认增长 1、非空两倍增长、溢出/最大容量饱和、分配失败、lvalue
copy/clone 失败的强异常边界、旧元素迁移/析构顺序与最终 commit。null/corrupt vector
布局没有运行时校验，属于调用方违反 `std::vector` 前置条件后的未定义行为。
