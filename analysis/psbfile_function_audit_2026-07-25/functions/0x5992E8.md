## Android 伪代码（9 行）

```text
GetDouble(self):
    node = self.node; tag = node[0]             // self/node/payload 均不校验
    if tag == 0x02: return 1.0; if tag == 0x03: return 0.0
    if tag in 0x04..0x08: return double(decodeSigned0_8_16_24_32(tag,node+1))
    if tag in 0x09..0x0C: return double(decodeSigned40_48_unsigned56_signed64(tag,node+1))
    if tag == 0x1D: return 0.0
    if tag == 0x1E: return double(readUnalignedFloat(node+1))
    if tag == 0x1F: return readUnalignedDouble(node+1)
    Throw(L"psb: can't convert value to double."); return 0.0  // 若 helper 返回
```

第 4 行中的 `0x04` decoder 默认值是零；第 5 行依次对应 `0x09/0x0A/0x0B/0x0C`。
以上 9 行覆盖全部 tag 分支、默认值、符号扩展方式、无长度检查边界和异常 helper 返回后的
fallback。
