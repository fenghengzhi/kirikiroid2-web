## Android 伪代码（8 行）

```cpp
tjs_error PSBValueDispatch::NativeInstanceSupport(flag, classid, pointer) {
    if (flag != TJS_NIS_GETINSTANCE) return TJS_E_NOTIMPL;
    static tjs_int32 valueClassId = 0;
    if (valueClassId == 0)
        valueClassId = TJSRegisterNativeClass(L"PSBValueClass");
    if (classid != valueClassId) return TJS_E_FAIL;
    *pointer = static_cast<iTJSNativeInstance *>(this); // ARM64: this + 8
    return TJS_S_OK;
}
```

完整边界是：非 GETINSTANCE 不读取缓存且不碰输出；缓存为 0 时每次都尝试注册并保存原样
返回值，随后仍进行比较；缓存非 0 时不再调用注册器；ID 不匹配不写输出；匹配时不检查
`pointer` 是否为空，直接写入借用的 secondary-base 接口指针且不 AddRef。函数也不检查
`valid_`、raw owner 或 node。
