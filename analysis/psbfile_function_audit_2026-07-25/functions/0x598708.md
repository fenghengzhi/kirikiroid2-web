## Android 伪代码（10 行）

```text
Adopt(self,data,u64 size,filter_ref):
    if size<0x40 || u32(data)!=0x00425350: return false  // 短路；未接管 data
    tmp.owner=new Owner; tmp.owner.ref=0; tmp.owner.{data,size}={data,bitcast_i64(size)}
    if data: tmp.owner.header=inline; copy sig/ver/encrypt; ptr[i]=data+u32(data+8..36)
    tmp.owner.ref=1; copy_assign(self,tmp): release/delete old if last; install new; tmp retain/release 抵消
    if filter.manager==null: return true                 // 默认空 filter；不校验 offsets
    filter.invoke(filter,self.owner)                     // 异常传播；不回滚已安装 owner
    o=self.owner; rebuild o.inlineHeader from current o.{data,size} before deciding validity
    ok=o.size>off8 && o.size>=off12/16/20/24/28/32 && o.size>off36  // signed i64 comparisons
    return ok                                             // false 仍保留新 owner；allocation 异常时 self 未改
```

第 4 行的 `8..36` 是步长 4 的八个 header offset；`>=off12/16/20/24/28/32` 是六个独立
合取条件，不是范围推断。伪代码覆盖输入 gate、空/非空 filter、构造默认 refcount、旧 owner
替换、回调异常、严格比较全部边界、false 后不回滚，以及 allocation 在修改 self 前失败的
边界。
