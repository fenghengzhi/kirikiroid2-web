## Android 关键伪代码（10 行）

```text
EnsureContainer(self, name):
  slash = name.IndexOf('/', 0); if slash < 0: return false
  container = name.SubString(0, slash)
  if self._file.Type == Object && self._container == container: return true
  file = new PSBFile(owner=null); emptyFilter = {}
  if !file.LoadStorage(container, emptyFilter): delete file; return false
  adaptor = CreateAdaptor(file, false, false); next = Void  // null 时 file 未认领
  if adaptor != null: next.SetObject(adaptor, adaptor); adaptor.Release()
  self._file = next; destroy(next); self._container = container; return true
  exception: 销毁已构造临时量并传播；adaptor 认领前的 raw file 可泄漏
```
