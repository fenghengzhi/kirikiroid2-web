## Android vtable / NCB / 调用链归属

`0x596F50` 是 Android `PSBValueDispatch` primary `iTJSDispatch2` vtable 的
`EnumMembers` slot 11；它不是 NCB typed wrapper、NCB callback 或注册函数。
canonical parent `0x597AD4` 构造该对象并安装含本入口的 vptr，所以 parent 边是
`[vtable-member]`，不能虚构为 `0x597AD4 -> 0x596F50` 的直接调用。

本函数对 `0x597B1C PSB_DecodeName_guess` 有一个保留的直接调用，因此后者是本节点唯一
canonical child。它还在 List/Dictionary 分支直接调用 `0x59673C
PSBValueDispatch_CreateVariant_guess`，但该 helper 的 canonical parent 已选为 `0x597854`；
这里仅记 cross-reference。两处 callback 调用是对传入 TJS closure Object 的
`iTJSDispatch2::FuncCall` vdispatch，不是 114-address psbfile MANIFEST 中的新节点。
