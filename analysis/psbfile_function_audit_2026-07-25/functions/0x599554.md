## Android vtable / NCB / 调用链归属

`0x599554` 是 raw `PSBRawNode` 的独立 type-category wrapper，不是 vtable member、
NCB wrapper、注册 callback 或 STL 实例。它的四个 Android emitted caller 都位于
Motion `ObjSource` 消费链；psbfile 的 dispatch/media/root 入口没有 `BL @599554`。
这里的“本 wrapper”必须与其底层共享 classifier 区分：`CreateVariant_guess`、
`IsInstanceOf`、`EnumMembers`、`GetCount`、`PropGetByNum`、`PropGet`、`GetString`、
`GetDictionaryKeys`、`ContainsDictionaryKey` 与 `PSBMedia::GetListAt` 源码级调用的是
classifier 边界，不是 raw-node wrapper；这些调用在 Android
target 中被分别内联、specialize，故不会出现在 `xrefs_to(@599554)`。
TASK_TREE 为 DAG spanning tree 选择 `PSBFile_GetRoot_guess@0x598A3C` 作为 raw-node
API 的逻辑分类父节点，关系准确标为 `[classification-only]`，不得伪装成
`[direct-call]`。本函数没有 TASK_TREE canonical child；default 的通用 TJS 异常
helper 不在 114-address psbfile function 集合内。
