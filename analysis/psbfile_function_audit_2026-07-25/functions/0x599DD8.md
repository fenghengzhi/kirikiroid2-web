## Android vtable / NCB / 调用链归属

本函数是 `PSBMedia` 的 `iTVPStorageMedia` vtable slot 10。Android 对入口没有直接
code xref；`sub_8EA200@0x8EA274` 通过 storage-media interface vdispatch 进入该槽，
且异常时释放 caller 已构造的返回字符串再继续 unwind。它不是 NCB 注册入口或 typed
wrapper，也不调用任何 psbfile 业务 helper；唯一 out-of-line callee 是旧字符串存储的
release helper。

TASK_TREE 把它挂在创建并注册 `PSBMedia` singleton 的 `0x59849C` 下，边类型为
`[vtable-member]`。该 parent 负责对象/vtable 归属，不应伪写成
`0x59849C -> 0x599DD8` 的直接调用。
