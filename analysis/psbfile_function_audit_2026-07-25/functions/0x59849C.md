## Android vtable / NCB / 调用链归属

`0x59849C` 本身不是 `PSBMedia` vtable member，而是 `PSBFile.dll` 模块的
PreRegist callback。静态初始化入口 `0x42CF28` 只把它的函数指针登记进 autoreg
对象；后续通用 NCB 模块加载流程才通过 callback vdispatch 调用它。该关系因此是
TASK_TREE 的 `[registration]`，不能写成 `0x42CF28 -> 0x59849C` 的直接调用。

回调第一次执行时内联构造采用 vptr `0x1A0B510` 的 `PSBMedia`；guard 完成后，
每一次回调（包括第一次）都把同一个进程期指针送入 `sub_8EA2C8` 注册链。

## Android 关键伪代码（8 行）

```text
preRegister():
  if atomic_load(local_guard).initialized == false:
    if __cxa_guard_acquire(local_guard):
      p = operator new(sizeof(PSBMedia))                 // 分配/构造异常向外传播
      construct p: vptr=0x1A0B510, ref=1, file/container=空状态
      local_static_ptr = p; __cxa_guard_release(local_guard)
      on initialization exception: __cxa_guard_abort(local_guard); rethrow
```

没有额外输入、返回默认值或静默失败分支。首次初始化失败时不注册；guard 未取得的
线程在 guard 协议完成后使用已发布指针；注册调用自身若抛出，已完成的 singleton
不会被回滚。
