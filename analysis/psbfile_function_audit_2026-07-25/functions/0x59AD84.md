## Android 伪代码（10 行）

```text
RegistEnd(d):
    if (!d.hasCtor): RegisterNCM(d.classObj,d.className,Wrap(NotImplCallback),d.className,nitMethod,flags=0)
    global = GetScriptDispatch()
    if (global == null): Log(L"No Global Dispatch, Regist failed."); return
    val = ObjectVariant(d.classObj, objThis=null)       // classObj 非空才 AddRef
    d.classObj.Release()                               // 无条件；null 是无保护的无效虚调用
    global.PropSet(TJS_MEMBERENSURE,d.className,0,&val,global) // 普通状态码忽略
    global.Release()
    destroy(val)                                       // Release variant 持有的 classObj
    helper/PropSet 异常无 fallback；val 已构造则清理后重抛，PropSet 异常跳过 global.Release
```
