## Android vtable / NCB / 调用链归属

`0x5996E4` 是 raw `PSBRawNode` 的 out-of-line resource accessor/helper，本身不在
vtable，也不是 NCB 注册函数或 typed wrapper。它从两指针 raw-node handle 读取
owner/header 与 node，返回借用的 chunk 指针并通过第二参数写 32-bit 长度。

Android 保留下来的实际 code callers 全在 psbfile 114-address MANIFEST 之外的 motion/
consumer 代码中；它们仅作为 cross-reference。本函数体内没有 out-of-line callee。
TASK_TREE 为了构造唯一 spanning tree，将它挂在具有内联同形资源解码的
`PSBMedia_GetResourceData_guess@0x59A0B4` 下：

```text
@0x59A0B4 PSBMedia_GetResourceData_guess
└─ [helper shape; no BL] @0x5996E4 PSBRawNode_GetResource_guess

motion/consumer callers ─[direct, cross-reference only]→ @0x5996E4
```

这条 canonical parent 关系只表达 helper/factorization 归属，不声称 Android 在
`0x59A0B4` 保留了调用指令。

## Android 关键伪代码（8 行）

```text
GetResource(self, size_out): h = self.owner.header; data = h.chunkData
if data == null: return null                                      // size_out 保持原值
offsets = packedView(h.chunkOffsets); lengths = packedView(h.chunkLengths); index = 0
switch self.node.tag: 19→u8, 1A→u16, 1B→(u32&0xFFFFFF), 1C→u32, default→0
length = widthTag(lengths)∈[0D,11] ? packed32(lengths,index) : 0
*size_out = length
offset = widthTag(offsets)∈[0D,11] ? packed32(offsets,index) : 0
return data + offset                 // W32 stride；无 count/index/null-out guard 或 fallback
```

本函数没有显式 throw/catch 或失败状态；有效 `chunkData` 后遇到损坏指针/越界表或空
`size_out` 时沿原始内存访问 fault，不吞并异常，也不把它转换为 null。

## 总判定

`EVIDENCE_LIMITED`

本轮 fresh decompile、完整反汇编及全部 xref 证明：Android 可观察的数据流、调用边界、
借用生命周期、packed 容器和显式失败行为均与本地实现一致，未发现确定 GAP。证据上限
只在 stripped/O3 已抹去的精确源码名字、packed helper factorization 与损坏内存 first-fault
顺序；这不能据无 `BL` 将 canonical `[helper]` 边改写为 direct-call。

## 所有确定 GAP

本 helper 本体无未闭合 GAP。二次 caller 审计曾发现 `sub_6DA454` 与本地
`SourceCache.cpp` 在 size-out 局部的未初始化状态、单槽复用、RL decoder 的 signed
`< 1` gate/source-end 顺序，以及 palette signed `/4` 上存在确定差异；当前已按
[`FOLLOWUP_0x6DA454.md`](../FOLLOWUP_0x6DA454.md) 闭合。其余源码 token 与
first-fault 歧义属于 `EVIDENCE_LIMITED`，不是确定偏差。

另一个 caller-level 确定差异是 `0x6948E8` 中 `pixel` strict raw-node 临时量的
full-expression 生命周期；当前 PlayerResource 链式调用已经闭合，详见
[`FOLLOWUP_PLAYERRESOURCE_LIFETIMES_2026-07-26.md`](../FOLLOWUP_PLAYERRESOURCE_LIFETIMES_2026-07-26.md)。
它不属于 `0x5996E4` helper 本体，因此不改写上表六维判定或 `EVIDENCE_LIMITED` verdict。
