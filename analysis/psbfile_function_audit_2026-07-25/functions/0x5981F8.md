## Android 伪代码（9 行）

```text
GetRootDispatch(self):
    owner = self.owner
    if owner == null: return null
    dispatch = operator new(sizeof(PSBValueDispatch))  // 失败异常直接传播
    install dispatch primary/secondary vtables; dispatch.refCount = 1
    entries = owner.header.entries                     // 不校验 header/entries
    dispatch.value = { owner, entries }; owner.refCount++  // 非原子、无溢出门控
    dispatch.valid = true
    return dispatch                                    // entries==null 仍返回 valid 对象
```

全部返回边界。
