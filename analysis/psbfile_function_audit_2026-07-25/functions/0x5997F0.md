## Android vtable / NCB / 调用链归属

`0x5997F0` 是 Android `PSBMedia` vtable `0x1A0B510` 的第一个 qword
（slot 0），与 slot 1 的 `0x599830` deleting-destructor 入口组成 Itanium C++
ABI 析构对。本节点不是 NCB wrapper；`PSBMedia` 由 PreRegist callback 创建并注册，
但运行期通过虚析构槽进入本入口。

canonical parent `0x599830` 与本节点是 `[lifecycle]` 归属：两者代表同一源码析构
函数的 complete/deleting ABI 变体。`xrefs_to` 与父节点反汇编上下文都没有证明
`0x599830 -> 0x5997F0` 的直接调用，因此不得把该边伪装成 `[direct-call]`。

正常调用链为：条件式 string backing Release → 无条件 Variant destructor 尾调用；
complete-destructor 不调用全局 `operator delete`，对象存储由外层删除语义管理。

```text
completeDestructor(self):                         // self 必须有效；无 null guard
  container = self->_container.Ptr
  self->vptr = PSBMedia_vtable@0x1A0B510
  if container != null: container->Release()
  self->_file.~tTJSVariant()                       // 无条件尾调用；无返回状态

  if container->Release throws: catch; terminate  // @59982C -> @520FAC
```
