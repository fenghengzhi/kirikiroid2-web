## Android vtable / NCB / 调用链归属

`0x59A284` 不是 `PSBMedia` vtable 成员，也不是 NCB method/property wrapper；它是
一个独立 emitted 的通用单字符 `ttstr` 搜索包装器。psbfile 范围内的调用关系是：

```text
@0x599E04 PSBMedia_EnsureContainer_guess
└─ [direct-call; canonical parent, call @0x599E38] @0x59A284

@0x59A4B0 PSBMedia_Resolve_guess
├─ [direct-call cross-reference @0x59A56C] @0x59A284
└─ [direct-call cross-reference @0x59A5A0] @0x59A284
```

本节点内部的 Android 调用链为“显式长度 1 的字符串分配 helper → 字符串版
`IndexOf` → 条件 Release”。TASK_TREE 选择 `0x599E04` 作为唯一 canonical parent；
`0x59A4B0` 的两条真实直接调用只记 cross-reference，不重复派发。

## Android 关键伪代码（8 行）

```text
IndexOfChar(self, character, start):                 // ABI 无默认参数；PSB caller 均传 0
  tjs_char one = character                           // 只物化一个 code unit，无结尾 NUL
  tmp.storage = AllocVariantString(&one, length=1)
  result = ttstr_indexOf(self, &tmp, start)           // start 原样传递，无范围门控
  if tmp.storage != null: Release(tmp.storage)
  return result                                       // 空串/character==0/miss 均为 -1
  exception after tmp construction: Release(tmp if nonnull); rethrow
  if stack_canary_changed: __stack_chk_fail()
```
