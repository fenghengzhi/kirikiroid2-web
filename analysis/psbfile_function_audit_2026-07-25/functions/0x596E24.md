## 源码级关键伪代码（8 行）

```text
if membername != null: return TJS_E_NOTIMPL
category = Classify(value.node[0])
if category == 4: expected = L"String"
else if category == 5: expected = L"Octet"
else if category == 6: expected = L"Array"
else if category == 7: expected = L"Dictionary"
else: return TJS_S_FALSE
return wcscmp_utf16(classname, expected) == 0 ? TJS_S_TRUE : TJS_S_FALSE
```

`Classify` 的 Android 完整实现见 `0x599554`：unknown 会抛
`psb: internal error: unknown internal type detected.\n`，若异常 helper 反常返回则给出
`-1`，因此仍命中上面的默认 false。`membername==null` 后无效 node 会在 tag 读取处
fault/UB；四个匹配 category 上 null `classname` 会在比较处 fault/UB，而默认 false 不读
`classname`。
