## Android 伪代码（9 行）

```text
LoadStorage(self,name,filter /* 原样转发；本体无内部默认替换 */):
    placed=TVPGetPlacedPath(name); stream=CreateStream(placed,READ); destroy(placed); if !stream return false
    if u64(stream.GetSize())<9: destroy(stream); return false
    size=u32(stream.GetSize()); data=AlignedAlloc(size,4); stream.ReadBuffer(data,size); dataSize=size
    if size>=11 && u32(data)==0x0066646D: expected=u32(data+4); decoded=AlignedAlloc(expected,4); actual=expected
    if MDF && uncompress(decoded,&actual,data+8,size-8)==0: dataSize=u32(actual); if decoded {AlignedDealloc(data); data=decoded}
    else if MDF && decoded: operator delete[](decoded)  // data/dataSize 保持原值
    ok=Adopt(self,data,dataSize,filter); destroy(stream); return ok  // false 不回收 data
    on exception: destroy constructed ttstr/stream, rethrow; do not reclaim allocated raw buffers
```

`MDF` 在第 6-7 行只表示第 5 行的长度/完整 u32 signature gate 已成立。伪代码覆盖 null
stream、64-bit 最小长度 gate、第二次 size 的 32-bit 默认数据流、非 MDF、zlib 成败、成功
但 null decoded、Adopt false、正常析构与异常泄漏边界；`filter` 没有函数内默认值，缺省空
filter 是 C++ caller 在调用边提供的形态。
