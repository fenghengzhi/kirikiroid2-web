## Android 伪代码（10 行）

```text
RegistBegin(self):
    tempName = ttstr(self.className)
    classObj = new tTJSNativeClassForPlugin(tempName, CreateEmptyAdaptor)
    self.classObj = classObj; destroy(tempName)
    id = RegisterNativeClass(self.className)
    if ClassInfo.initialized: throw L"Already registerd class."
    ClassInfo = { initialized=true, name=self.className, id=id, obj=classObj }
    classObj.SetClassID(id)
    classObj.RegisterNCM(L"finalize", NativeMethod(EmptyCallback), self.className, nitMethod, 0)
    return void  // 构造失败清理 allocation/temp；其后失败在本入口不回滚
```
