## Android 伪代码（9 行）

```text
rootTypedInvoke(io, method, native):
    if native == null: return false
    dispatch = invoke_pointer_to_member(method, abi_adjust(native))  // root 绑定 @5981F8
    if io.result == null: return true  // 不转换，也不释放 dispatch
    tmp = ObjectClosure(dispatch, dispatch)  // 非空时分别 AddRef；空时保持 null
    io.result.CopyRef(tmp)                    // 复制两只引用，并释放旧 result 内容
    destroy(tmp)                              // CopyRef 抛出时也执行，然后继续抛出
    dispatch.Release()                        // 无条件；dispatch==null 时故障
    return true                               // 其余异常直接传播
```

该伪代码覆盖 native 空值、pointer-to-member ABI 分支、可空 result、dispatch 空/非空、
Object/ObjThis 双引用、临时对象异常清理、无条件 Release 与全部正常返回值。
