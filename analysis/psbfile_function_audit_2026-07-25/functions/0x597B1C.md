## Android 伪代码（10 行）

```text
DecodeName(out, owner, nameIndex):
    packed(A): count=tag 0x0D/0E/0F/10 的 1/2/3/4-byte 值，否则 0；width=A[tag-11]-12；values=A+tag-10；next=u32(tag-10+count*width)
    read(P,i): P.width in 1..5 ? load32(P.values+u32(i*P.width)) & mask(P.width) : 0
    names=owner->header->names                                      // 无 null/header/data 检查
    charset=packed(names); namesData=packed(names+charset.next)
    nameIndexes=仅取位于 namesData+namesData.next 的 width/values；index=read(nameIndexes,nameIndex) // 无 count/range gate
    node=read(namesData,index); bytes=empty vector<char>            // node==0 保持空
    while node!=0: parent=read(namesData,node); bytes.push_back(u8(node-read(charset,parent))); node=parent
    reverse(bytes); out.assign(bytes.begin,bytes.size)              // 空路径传 nullptr,0
    on vector growth/string assign exception: delete live bytes buffer and rethrow
```

`mask` 对 width `1..4` 保留对应低 8/16/24/32 位；width `5` 依 AArch64 W-register shift
modulo 规则保留低 8 位。所有 table displacement 和 index product 都先按 W32 回绕，再以
零扩展地址增量使用；没有序列化区长度、nameIndex count 或 parent-cycle gate。
