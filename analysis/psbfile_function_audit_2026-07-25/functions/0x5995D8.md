## 源码级关键伪代码（7 行）

```text
ContainsDictionaryKey(self,key): tmp={owner:null,node:null}             // 无 null gate
category=Classify(*self.node)                                          // unknown 抛精确诊断
if category != 7: result=false                                         // helper 若返回也为 false
else: result=GetDictionaryValue(self,key,&tmp)
if tmp.owner != null: --tmp.owner.refcount
if decrement reached zero: destroy tmp.owner.payload_at_0x58; delete tmp.owner
return result; exception paths perform the same tmp cleanup and resume unwind
```
