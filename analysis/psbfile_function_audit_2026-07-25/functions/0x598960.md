## Android 伪代码（9 行）

```text
Refresh(self, validateOffsets):                           // 无 self/data/size 前置 guard
    data=self.data; self.header=&self.headerStorage
    header.{signature,version,encrypt}={u32(data),u16(data+4),u16(data+6)}
    off[0..7]=u32(data+8,+12,+16,+20,+24,+28,+32,+36)
    header.{encryptData,names,strings,stringsData,chunkOffsets,chunkLengths,chunkData,entries}=data+off[]
    if !validateOffsets: return true                      // false 模式不校验；view 已写入
    if i64(self.size)<=off[0]: return false               // signed compare；encrypt 严格 `< size`
    if any i64(self.size)<off[1..6]: return false         // 中间六项允许 `offset == size`
    return i64(self.size)>off[7]                          // entries 严格 `< size`；失败不回滚 view
```
