## Android 伪代码（8 行）

```text
GetRoot(self, out@X8):
    owner = self.owner                         // self==null：此处失败，out 未写
    header = owner.header                      // owner==null：此处失败，out 未写
    entries = header.entries                   // header==null：此处失败，out 未写
    out.owner = owner
    if owner != null: owner.refCount = u32(owner.refCount + 1)  // 非原子、无溢出检查
    out.node = entries                         // entries 可为 null
    return out                                 // X8 间接返回；X0 仅保持 self
```

伪代码覆盖了全部读取/写入顺序、唯一条件、32-bit 默认回绕语义，以及 self/owner/header
无防护和 null entries 被接受的失败/边界行为；本函数没有其他默认值或错误返回。
