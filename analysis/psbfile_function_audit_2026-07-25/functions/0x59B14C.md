## Android 伪代码（8 行）

```text
FactoryFuncCall(membername, numparams, param, objthis):
    if membername != null: return TJS_E_MEMBERNOTFOUND
    if numparams == 1 && param[0].Type() == tvtVoid: return TJS_S_OK
    PSBFile *inst = null; r = boundFactory(&inst, numparams, param, objthis)
    if r != TJS_S_OK: return r                           // 不清理 inst
    adp = null; ok = objthis && SUCCEEDED(objthis.NIS(GETINSTANCE, classId, &adp)) && adp
    if ok: adp.instance = inst; return TJS_S_OK           // inst 可为 null
    if inst != null: delete inst; return TJS_E_NATIVECLASSCRASH
```

上面覆盖 member-name、void-shell、callback 的成功/非零/异常、null `objthis`、NIS 失败、
null adaptor、null/non-null `inst` 与最终清理边界。`numparams==1` 时 Android 直接解引用
`param` 和 `param[0]`，没有为违反 TJS ABI 的 null 参数表增加保护。
