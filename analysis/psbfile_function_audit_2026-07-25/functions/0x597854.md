## Android 伪代码（10 行）

```text
PropGet(self, flag, membername, hint, result, objthis):
    if membername == null: return -1002; if !self.valid || self.owner == null: return -1006
    tag=*self.node; category=GetTypeCategory(tag) // node/result 不另检；hint、objthis 不使用
    if category == 6 && membername == L"count": decode 0x0D/0x0E/0x0F/0x10 as u8/u16/u24/u32, default count=0
        assignInt32(result, count); return 0
    if category == 7: construct one NarrowHolder(membername); short-circuit FindNameIndex(names,Buf,idx) && FindDictionaryOffset(node+1,idx,off)
        if hit: CreateVariant(self,result,node+1+off); destroy holder; return 0; else destroy holder
    classifier unknown 若 throw helper 返回，则 category=-1 并进入同一 miss 尾链
    if flag & 0x400: return -1001
    ClearVariant(result); return 0
```

伪代码覆盖全部 tag 分支、packed count 默认值、两级 dictionary 短路、三个错误码、未知类型
异常以及 miss 是否清空 result 的边界。holder 构造、helper/CreateVariant 或 result 写入抛出的异常均
直接传播；dictionary holder 已构造后会由 unwind 清理。
