## Android 伪代码（9 行）

```text
GetCount(self, result, membername, hint, objthis):
    if !self.valid: return TJS_E_INVALIDOBJECT
    if self.value.owner == null: return TJS_E_INVALIDOBJECT
    if membername != null: return TJS_E_NOTIMPL
    category = GetTypeCategory(self.value.node[0])
    if category != 6: return TJS_E_NOTIMPL   // unknown helper-return category=-1
    count = node[1]==0D ? u8(node+2) : 0E ? le16(node+2) : 0F ? le32(node+2)&FFFFFF : 10 ? le32(node+2) : 0
    *result = tjs_int(count); return TJS_S_OK
```

该伪代码覆盖全部条件分支、默认值和失败边界：未知 raw tag 抛错，而未知 packed count tag
不是错误，固定写零并成功返回。
