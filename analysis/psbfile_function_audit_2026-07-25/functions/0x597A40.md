## Android 伪代码（9 行）

```text
Release(self):
    count = uint32(self.refCount - 1); self.refCount = count       // 非原子，可回绕
    if count != 0: return count
    owner = self.value.owner
    self.primaryVptr = @1A0B3D8; self.secondaryVptr = @1A0B4E8
    if owner != null:
        ownerCount = uint32(owner.refCount - 1); owner.refCount = ownerCount
        if ownerCount == 0: aligned_dealloc(owner.data); delete owner
    delete self; return 0       // cleanup 异常进入 terminate；无 guard/fallback/rollback
```

该伪代码覆盖 dispatch/owner 两级引用计数的全部分支、null owner、共享/最后 owner、两级
unsigned 回绕、双 vptr 析构 shape、正常返回值以及 cleanup 异常终止边界。
