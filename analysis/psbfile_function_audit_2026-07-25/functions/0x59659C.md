## Android 伪代码（10 行）

```text
tag = dictionary[0]; count = decodeCount(dictionary, tag)               // 0x0D..0x10；default 0
widthTag = dictionary[tag-0x0B]; keysBase = dictionary + tag-0x0A
if count == 0: return false                                               // outOffset 不写
lower = 0; upper = count
while lower < upper: middle = u32(lower + upper) >> 1
    candidate = decodePacked(keysBase + u32(middle*(widthTag-0x0C)), widthTag) // width 1..5；否则 0
    if candidate == nameIndex: break
    if candidate >= nameIndex: upper = middle; else: lower = middle + 1
if lower >= upper: return false                                           // outOffset 不写
offsets = dictionary + keysBytes_u32; *outOffset = u32(keysBytes_u32 + offsetsBytes_u32 + offsets[middle]); return true
```

`decodeCount` 的非法 tag 默认值为 0；`decodePacked` 的非法 width 默认值为 0。
第二张 offsets 表的 count 只参与其 byte displacement，Android 不检查
`middle < offsets.count`，也不检查输入指针、序列化区长度或最终目标边界。width 5
遵循 AArch64 W-register shift modulo 行为，只保留未对齐 32 位读取值的低 8 位。
