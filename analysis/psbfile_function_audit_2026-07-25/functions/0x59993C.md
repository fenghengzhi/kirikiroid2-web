## Android vtable / NCB / 调用链归属

`0x59993C` 是 `PSBMedia` vtable `0x1A0B510` 的 slot 08。canonical parent
`0x59849C` 是 `PSBFile.dll` 的 PreRegist callback：它构造并注册采用该 vtable 的
process-lifetime `PSBMedia`，但不直接 `BL 0x59993C`，所以 TASK_TREE 的父边正确标为

虚分派进入本函数；本函数本身不是 NCB method/property wrapper。

本入口保留的 psbfile 内部直接调用只有 `PSBMedia_EnsureContainer_guess@0x599E04` 与

## Android 关键伪代码（9 行）

```text
Open(self, name, flags):                              // flags 完全忽略
  if !EnsureContainer(self, name): return nullptr
  uint32 size                                        // 无本地默认初始化
  data = GetResourceData(self, name, &size)
  if data == nullptr: throw eTJSError("%1: cannot open psbfile", name)
  raw = operator new(sizeof(tTVPMemoryStream))        // new 失败直接向外传播
  try: construct tTVPMemoryStream(raw, data, size)    // 借用 data，不持有 owner
  catch: operator delete(raw); rethrow
  return raw
```

因此显式失败边界依次是：container 不可用时静默返回空；container 可用但资源不存在时
抛 `eTJSError`；分配或构造异常向外传播，且只有构造已取得存储后失败才释放该对象存储。
