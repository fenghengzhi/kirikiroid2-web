## Android 伪代码（10 行）

```text
FuncCall(w, membername, result, argc, argv, objthis):
    if membername != null: return TJS_E_MEMBERNOTFOUND
    if objthis == null: return TJS_E_NATIVECLASSCRASH
    if result != null: result.Clear()
    if argc < 1: return TJS_E_BADPARAMCOUNT
    (status, adaptor) = objthis.NativeInstanceSupport(GETINSTANCE, PSBFileClassID)
    if status < 0 or adaptor == null or adaptor.native == null: return TJS_E_NATIVECLASSCRASH
    arg0 = CopyFirstArgument(argc, argv); ok = (adaptor.native .* w.method)(arg0)
    if result != null: *result = Integer(ok & 1); destroy arg0; return TJS_S_OK
    // 已构造临时量遇异常逆序析构后重抛；额外参数忽略；argv 本身无 null 检查
```

native-instance 失败边、正常/无 result 调用和异常清理；`flag/hint` 在本入口未使用。
