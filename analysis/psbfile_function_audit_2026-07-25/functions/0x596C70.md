## Android 关键伪代码（9 行）

```text
getResource(self, node, size):
  header = self.value.owner.header; data = header.chunkData
  if data == null: return null                                      // 不写 *size
  offsets = packedView(header.chunkOffsets); lengths = packedView(header.chunkLengths)
  switch node[0]: 0x19 idx=u8; 0x1A idx=u16; 0x1B idx=u32&0xFFFFFF; 0x1C idx=u32; default idx=0
  len = lengths.elemTag in [0x0D,0x11] ? readMasked(lengths, idx) : 0
  *size = len
  off = offsets.elemTag in [0x0D,0x11] ? readMasked(offsets, idx) : 0
  return data + off
```

`readMasked` 在 Android 中以 W32 计算 `idx * width`，用该零扩展偏移执行 unaligned
32-bit load，再按 width 掩码；width 5 依 AArch64 variable-shift modulo 规则保留低 8 位。
函数没有 self/owner/header/node/size/table/index bounds guard：除显式 data-null 分支外，
非法地址按原始裸访问边界失败；没有异常捕获或 fallback。
